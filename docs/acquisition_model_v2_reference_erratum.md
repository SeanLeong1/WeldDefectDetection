# Bibliographic correction, 28 September 2026

The prospectively frozen `acquisition_model_v2.md` contains an extra `but-` in its NIST visibility-paper URL. The working primary-source link is:

[Newbury (2018), High Resolution Is Often Sought in SEM Imaging, But Establishing Visibility May Be the Challenge](https://www.nist.gov/publications/high-resolution-often-sought-sem-imaging-establishing-visibility-may-be-challenge).

The [NIST-hosted paper](https://tsapps.nist.gov/publication/get_pdf.cfm?pub_id=925016) discusses how detector efficiency, beam current and dwell time affect feature visibility through signal noise. It does not calibrate this project's noise amplitudes. This correction changes no model, parameter, dataset or decision threshold. The frozen source snapshot and its hashes are retained.
